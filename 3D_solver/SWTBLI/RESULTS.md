# SWTBLI 計算結果のまとめ

入射衝撃波 / 乱流境界層干渉（M0 = 2.28、目標 Re_θ ≈ 500）のステージごとの計算結果です。
§1〜§7 は格子世代 1（IUSTI 相当の θ = 9.5°、A1〜B0）、§8 以降は格子世代 2
（格子 1.5 倍細分化、高さ 18δ、θ = 12° で大規模剥離を狙う、G0〜）の結果です。手法と境界条件の設計は `3D_solver/CLAUDE.md` の
「SWTBLI: two coupled domains」節にあります。ここには **結果の数値** だけを書いています。

* 元データ: `3D_solver/SWTBLI/runs/<stage>/analysis/*.json`
  （`python -m ouxsbli.analysis.swtbli_stats {turb|track|report|zcorr|gif|wall} runs/<stage>` で生成）
* A1〜A2c_3 の `data/`（VTK）は解析後に削除しました（約 81 GB）。`analysis/`・`gif/`・`recal/` は残っています。
  B0 は θ = 9.5° の比較基準として `data/` も残しています。
* `runs/` は `.gitignore` の対象です。下のリンク先の図・GIF はローカルにしかありません。
* 長さは δ = `blt` = 1.0724 mm（入口 δ99 の設定値）、時間は δ/u0 = 1.968 µs（= 182 step、
  dt = 1.08e-8 s）で無次元化しています。x の原点は非粘性での入射点 `x_imp` です。

* **接続部 p'rms,wall の 5〜7 % の差**: 平均量（u, p, Cf）は 1.5 % 以内で一致しています。
  ずれているのは変動量だけです。

  原因はまだ切り分けていません。

  f ≈ 1.02 で等エントロピー的にスケーリングしていることと整合する大きさです
  （`CLAUDE.md` の「Incident shock」節を参照）。基準を p2 にするか f·p2 にするかは未決定です。

## 8. 格子世代 2（2026-11-10 〜）

### 8.1 変更の理由と内容

| 指摘 | 世代 1 での状況 | 世代 2 の対応 |
|---|---|---|
| 反射衝撃波背後の非物理な縞状振動 | schlieren・p'rms に反射衝撃波と平行な縞。9.5δ より上の伸長域（+5 %/cell）では格子点状のパターン | dx0 = dy = 0.0604δ → **0.0403δ**（TBL 生成領域と共通）。一様域を 16δ まで、その上は +3 %/cell |
| 上部境界からの反射が境界層に届く | 反射衝撃波が x_imp+11δ で上端に達し、上端で反射した波が x_imp+21〜25δ で境界層に戻る（一様格子内） | 高さ 12.2δ → **18.1δ**。入口〜x_imp を 25δ → 31δ、一様格子を x_imp+22δ まで |
| 剥離が小さい | 時間平均 Cf<0 は約 6δ、気泡は薄い | θ = 9.5° → **12°**（p3/p1 = 2.86 → 3.66）。G0（9.5°）→ C1（11°）→ C2（12°）と段階的に上げる |

* 格子: TBL 274×128×114、SBLI 1397×455×114（7200 万点、世代 1 の 3.8 倍）。GPU メモリ 20.4 GB（SBLI 側）。
* dt、dyw0、dz、スパン 4δ は世代 1 と同じです。
* 初期場は `regrid.py` で B0 の終了状態を補間しました。補間前後で、瞬時のスパン平均値は次のとおりです。
  * Cf の差: 14 点中 13 点で 0.05e-3 以下。剥離域の ξ = −4 だけ −2.71e-3 → −2.39e-3。
  * p_w の差: 1.1 % 以内。
* 計算コスト: **0.48 s/step**（G0: 9110 step で 72 分 40 秒）。150 δ/U ≈ 3.6 時間、300 δ/U ≈ 7.3 時間。
* 解析と間引き: 各ステージの後に `post_stage.sh` が turb/track/report/wall/gif を実行し、
  `data/` を最後の 3 枚に間引きます（SBLI 1 枚 1.5 GB）。

### 8.2 G0（θ = 9.5°、50 δ/U、補間の過渡を流す）

* 上流 TBL（`turb`、5 項目すべて合格）: Cf = 3.70e-3（Van Driest II −0.9 %）、Re_θ = 582、Re_τ = 134、
  δ99/blt = 1.20、u_rms+ ピーク 2.78。B0（3.65e-3、584、130、1.18、2.83）とほぼ同じです。
* 接続部: Δu 0.33 %、Δp 0.26 %、ΔCf 0.9 %（いずれも B0 より小さい）。Δp'rms,wall は 7.3 %（B0 6.7 %）。
* 50 δ/U では補間の過渡がまだ残っています: 上部領域を下流へ流れる弱い不連続面（旧上端の継ぎ目）と、
  x ≈ x_imp に一度だけ現れた弧状の波。平均場の診断（`post_shock` の p'rms/p2 = 2.6 % など）は
  この過渡を含むので、世代 1 との比較には使っていません。
* 上部境界: 反射衝撃波が上端に達するのは x_imp+24δ 付近（一様格子の終端付近）です。上端で反射した波の
  着地点の見積もりは x_imp+45δ で、領域の外になります（B0 は x_imp+28δ）。

**反射衝撃波背後の縞の振幅（同じ θ = 9.5° での比較）**: 瞬時場の各 z 断面・各行（4δ < y < 8δ）で
反射衝撃波の位置を dp/dx 最大点として求め、その背後の帯で ρ と 0.3δ 移動平均との差の rms を取りました
（B0・G0 とも最後の 3 スナップショット）。

| 帯（衝撃波背後） | B0（dx0 = 0.0604δ） | G0（dx0 = 0.0403δ） | 比 |
|---|---|---|---|
| 0.3〜1.2δ | 0.044 ρ0 | 0.026 ρ0 | 0.60 |
| 0.5〜2.0δ | 0.013 ρ0 | 0.0074 ρ0 | 0.56 |

縞は細分化で約 4 割小さくなりましたが、消えてはいません。衝撃波直後の約 1δ の帯に、格子間隔程度の
細かい縞が残っています。格子に対して斜めに動く衝撃波が出す誤差なので、1.5 倍の細分化では
振幅が下がるだけです。
世代 1 の伸長域（9.5δ 以上）に出ていた格子点状のパターンは、世代 2 では見られません。

### 8.2b C1（θ = 11°、150 δ/U、218 分）

* 干渉域の拡大が続いています。`track` の窓平均（W = 125 δ/U）で x_0 は −7.00 → −6.56 → −7.60、x_sh は
  −5.23 → −4.87 → −5.98 です。区間の最後で、瞬時の x_0 は約 −8.5δ に達しています。
  瞬時の L_sep は約 12.5δ です。θ = 9.5° では x_0 ≈ −6.9δ、L_sep ≈ 9〜10δ でした。
* 時間平均 Cf が負になる範囲（区間平均の GIF）は ξ ≈ −7.5〜+0.5 で、θ = 9.5° の約 6δ から約 8δ に伸びています。
* 上流 TBL: Cf = 3.70e-3（Van Driest II −0.7 %）、Re_θ = 585。直近 30 δ/U の Cf ドリフト（+6 %、相対標準偏差 3.4 %）
  だけが判定に落ちています。他の 4 項目は合格です。
* 接続部: Δu 0.18 %、Δp 0.29 %、ΔCf 1.2 %、Δp'rms,wall 4.2 %（世代 1 は 5.5〜6.7 %）。
* 上部境界:
  * 反射衝撃波が上端を出るのは ξ ≈ 20 です。上端で反射した波の着地点の見積もりは ξ = 40 で、
    領域（ξ ≤ 31.5）の外です。schlieren でも、この波は出口の手前で境界層に届いていません。
  * 入射衝撃波が上端に入る x_top から、θ = 11° の流線方向に弱い線が 1 本伸びています。
    上端の状態 1/2 を tanh でつないでいる部分から出るエントロピー層と考えられます。
    この傾きでは壁に届くのは約 90δ 下流で、領域の外です。
* θ を上げた直後は、上端の圧力レベル f が 1.089 から始まりました。上流側の平均窓に、θ = 9.5° の
  入射衝撃波がまだ残っていたためです。f は約 27 δ/U で 1.027、約 55 δ/U で 1.021 まで戻っています
  （τ = 10 δ/U の移動平均）。
