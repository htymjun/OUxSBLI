# SL_cross


`SL_spatial_inlet` を基にした、主流 x 方向へ延びる十字型せん断層。
初期場の横断面は **yz 平面**。

## 初期場・流入平均場

```
a = tanh(2*(y-Ly/2)/delta_bl)
b = tanh(2*(z-Lz/2)/delta_bl)
u = (u1+u2)/2 + (u1-u2)/2 * a*b
T = (T1+T2)/2 + (T1-T2)/2 * a*b
rho = p/(R*T)
v = w = 0   (初期場)
```

| | z < Lz/2 | z > Lz/2 |
|---|---|---|
| y > Ly/2 | 低速 | 高速 |
| y < Ly/2 | 高速 | 低速 |

流入の3速度成分には元ケースと同じ5%のGaussian擾乱を与える。
包絡線は `1-a*a*b*b` とし、両方のせん断層に局在させる。
初期場と流入・側方スポンジの目標値は同じ `cross_profile` をセル中心で評価する。

## 格子と境界

- x・y の領域長、格子生成、流速・温度・圧力は元ケースを継承。
- z の主領域は現在の80 mmを維持。両側50 mmのバッファを含めて180 mm。
- z の主領域256点、各バッファ14点、ゴーストを含め `nz=286`。バッファ点数は `nz_buf=ny_buf`。
- **y/zとも同じ格子生成関数**を使用。主領域は `atanh(s*tanh(1.7))/1.7` による中心集中、
  バッファは接続部の伸び率からコサインランプで滑らかに伸長する。
- 現在はy/zの領域長・点数が同じなので座標と格子間隔も一致する。
- `BC_Z=True`：周期境界用カーネルから開放境界用カーネルへ切り替える。
- x出口、y両端、z両端は保存変数の外挿。z両端は実座標の格子間隔比を使う線形外挿。x/yは元の処理を継承。
- zスポンジはyと同じ最大係数とsmoothstepランプを使用。外側7点を減衰領域にする（点数基準であり物理長の半分ではない）。
- y/zスポンジは十字型平均場へ緩和し、重なる部分の重みを `1-(1-sigma_y)*(1-sigma_z)` で結合する。
- xスポンジは入口面の瞬時 **yz分布** を各点ごとに保持して目標とする。元ケースのz平均は十字分布を消すため使用しない。
- `RESTART=False`：新しい初期場から開始。元ケースの再開データを流用しない。
- 元ケース同様 `RK=4`, `COMMZ=False`, `RESCALE=False`。流入乱数の更新回数もRK4に対応する。

既定格子は `888 x 286 x 286`（約7264万点）。旧一様z格子の再開データとは互換性がない。

## 非一様z格子の時間更新

既存の出力・物理量復元との互換性のため、`QJ=U/Jref` の2次元配列を維持する。
`1/Jref = dx_cell*dy_cell*dz_ref` とし、`dz_ref` は中心付近の代表幅。
各点の物理体積は `Vcell=dx_cell*dy_cell*dz_cell(k)` なので、共有 `calc_steps.f90` の
流束差による更新量に `dz_ref/dz_cell(k)` を掛ける。これにより物理量の更新は
局所体積で割った流束収支となる。粘性・センサー用の `zetaz=1/dz` は既存処理が局所幅を使用する。
この補正はSL_crossのCMakeで定義する `OUXSBLI_STRETCHED_Z` のみで有効になる。
他ケースの計算式・ビルド設定は変更しない。現在の `COMMZ=False` で使用する。


## ビルド・実行

リポジトリのルートから：

```sh
cmake -S 3D_solver/SL_cross -B 3D_solver/SL_cross/build
cmake --build 3D_solver/SL_cross/build -j 4
cd 3D_solver/SL_cross
bash calc.sh
```

NVHPC、CUDA、MPIを使用。GPUターゲットは元ケースと同じA100（cc80）。
`calc.sh` は元ケースと同じ2 MPIプロセスで起動する。

## 検証

```sh
python3 3D_solver/SL_cross/verify.py
```

`verify.py` は一時ディレクトリーにCPU用の縮小版を生成し、実際のFortranケース処理を
`gfortran -fcheck=all` で実行する。格子・四象限・圧力・初期/流入整合・スポンジ・
全方向と角の外挿を確認する。加えて実際の共有 `calc_R` をCPU化し、製造した流束による
xyz各方向の微分、体積重み付き収支、一様状態・一様格子への極限を検証する。
GPUカーネルや時間積分全体の検証ではない。

作成時に既定設定のNVHPCビルドとこの検証が成功。
作成環境ではGPUドライバーが利用できないためGPU時間発展は未実行。
