# 主計算領域の格子設定

`mod_globals.f90` でx主領域全体と、y中心の一様区間を指定する。

| 設定 | 既定値 | 意味 |
|---|---:|---|
| `Lx_main` | 400 mm | x主計算領域全体の長さ（一様） |
| `nx_main` | 856 | x主領域の両端を含む格子生成点数 |
| `Ly_uniform` | 20 mm | y主領域中央の一様区間の全幅 |
| `ny_uniform` | 128 | その区間の両端を含む格子生成点数 |

xは0〜400 mmの主計算領域全体が一様。yは主領域中央を挟む幅20 mmが一様で、
その両外側を主領域端まで伸長する。現在の絶対座標ではy一様区間は80〜100 mm。
一様幅はx約0.46784 mm、y約0.15748 mm。
既存の格子生成用配列 x/y を作った後、隣接点の中点をソルバーの座標 xc/yc とする規約は維持する。
上表の点数はこの生成用配列の点数であり、セル数ではない。

## y主領域の伸長区間

一様区間の幅を h、伸長区間の区間数をNとし、
`width(j)=h+A*smoothstep((j-1)/(N-1))` とする。
`smoothstep(t)=10*t^3-15*t^4+6*t^5`。
係数Aは伸長区間の総長に一致するよう求める。
一様区間直後の幅はhで一致し、以降は滑らかに増加する。

- `nx_main >= 3`、`2 <= ny_uniform <= ny_main` が必要。
- yを対称にするため `ny_main-ny_uniform` は偶数。
- 伸長区間長は `N*h` 以上が必要。不整合はエラーにする。
- y主領域全体を一様にするときは一様区間の長さ・点数を主領域全体と一致させる。

## バッファとの独立性

xの等間隔生成と、yの生成関数 `grid_partitioned.f90:partitioned_axis` はバッファの設定を参照しない。
`Lx_buf/nx_buf`、`Ly_buf/ny_buf` は従来と同じくバッファだけを指定する。
バッファは主領域末端の幅・伸び率を引き継ぎ、別にコサインランプの伸長率を求める。
バッファ長を変更しても主領域の格子間隔は変わらない。
yの絶対座標原点は下バッファ長に応じて移動する。
バッファが接続幅に対して短すぎる場合は、主領域を変更せずエラーにする。

z格子・初期場の式・流入/流出処理は維持。
旧格子の再開データは補間なしに使用できないため `RESTART=False` に変更した。

## 検証・ビルド

リポジトリルートで：

```sh
python3 3D_solver/SL_spatial_inlet/verify_grid.py
cmake -S 3D_solver/SL_spatial_inlet -B 3D_solver/SL_spatial_inlet/build
cmake --build 3D_solver/SL_spatial_inlet/build -j 4
```

検証は実際のFortran格子生成処理をCPU上で実行し、一様幅、接続、単調伸長、対称性、
主領域・バッファ長、バッファ設定からの独立性、不正設定の検出を確認する。
GPU時間発展の検証ではない。起動時には変更後の格子に対するCFL診断も出力される。
