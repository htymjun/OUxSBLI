# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub Issues or
Discussions.

If you discover a security vulnerability affecting OUxSBLI or its supporting
infrastructure, please contact the repository maintainer privately.

Public Issues should be used for ordinary bugs, numerical problems,
performance issues, feature requests, and validation problems.

## Scope

Security reports may include vulnerabilities in:

- repository workflows
- documentation deployment
- build or automation scripts
- dependency handling
- other project infrastructure

Numerical bugs and ordinary CFD implementation errors should normally be
reported through the appropriate public Issue template.
